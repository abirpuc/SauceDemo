# UI Automation Testing for Swag Labs website Using Playwright

## UI Url: https://www.saucedemo.com/

## Project overview:

### This is an e-commerce website; there are many types of users. Automate this site using Playwright with JavaScript using the page object model.

- Try to log in with Loked_out_User.
- Log in error message validation.
- Log in with standard_user.
- Reset the app state.
- Select random products.
- Validate the product name & total price.
- Log in with the performance_glitch_user user.
- Sort the products from z to a.
- Validate the order successful message.
- Log out the user.

## Tootls & Technologies:

- VS Code.
- Playwright.
- JavaScript.
- Faker JS.

## Test cases: All test cases are inside the tests folder.

  ### Test cases are 

    1. lokedUser.spec.js. Run the test case using this command: npm run lokedUser
    2. glitchuser.spec.js. Run the test case using this command: npm run glitchuser
    3. standardUser.spec.js. Run the test case using this command: npm run standardUser

## Run all the test Cases: npm run test

## For the test Report: npx playwright show-report
